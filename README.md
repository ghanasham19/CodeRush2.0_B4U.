# 📄 EvidenceHub AI
**Agentic Research & Content Paywall via x402 Micro-transactions**

EvidenceHub AI is a decentralized, two-sided marketplace designed to solve the broken economic models of traditional web subscriptions and IP piracy. Built for the **Agentic Research and Content Paywall** hackathon challenge, it empowers publishers to monetize proprietary research securely, while allowing researchers and AI agents to pay *strictly* for the insights they consume using instant Web3 micro-transactions.

---

## 🚀 The Core Problem vs. Our Solution

**The Problem:** 
Currently, researchers are forced into expensive, recurring subscription lock-ins just to access a fraction of the content they need. Meanwhile, publishers face constant IP leakage as PDFs are shared for free, losing downstream revenue. 

**Our Solution:** 
EvidenceHub AI utilizes the emerging **x402 (Payment Required) protocol** alongside the **Algorand blockchain** to create a frictionless, pay-per-prompt micro-economy. 
* 🚫 **No subscriptions.** 
* 🚫 **No AI hallucinations.** 
* ✅ **Instant, peer-to-peer settlement.**

---

## ✨ Key Features & Hackathon Deliverables

### 1. 📚 Smart Content Catalog & Preview-Before-Pay
* **Publisher Upload:** Publishers upload PDF research papers and define custom pricing for specific analytical insights.
* **Metadata Preview:** Researchers and autonomous agents can preview the document title, available query metadata, and cost *before* committing to a purchase, preventing blind spending.

### 2. ⚡ x402 Payment Adapter (Algorand Lute Wallet)
* We replaced traditional paywalls with an **Algorand Web3 execution layer**.
* Every time a user or agent queries the document, a **0.05 ALGO** transaction is cryptographically signed and settled instantly on the Algorand TestNet, distributing funds directly to the publisher without intermediaries.

### 3. 🧠 Evidence-Aware AI Oracle (Strict Provenance)
* Powered by Google's **Gemini Generative AI**, our Oracle is locked into a highly structured, forensic system prompt.
* **Zero Hallucination Guarantee:** If the answer is not explicitly in the document, the AI is programmed to reject the prompt rather than hallucinate.
* **Citation Enforcement:** Every generated claim strictly appends a provenance tag (e.g., `[Source: Page X, "Exact Section Heading"]`).

### 4. 🧾 Decentralized Receipts (Zerion Integration)
* Utilizing the **Zerion API**, every successful AI prompt generates an immutable, on-chain receipt.
* Researchers can instantly verify their x402 micro-payment, viewing the exact block status, network fee, and timestamp to confirm ownership of the insight.

### 5. 📊 Dual-Sided Financial Terminal (Zerion Analytics)
* **Publisher Revenue Dashboard:** Publishers can view a live feed of all incoming micro-payments (ALGO) generated by their intellectual property.
* **Researcher Expense Tracker:** Researchers can track their exact Web3 budget, viewing exactly how much ALGO they have spent across different research papers.
* *Note: Includes a robust fallback sandbox to ensure continuous dashboard availability during hackathon API rate-limits.*

## ⚙️ Architecture & Data Flow

1. **Upload Phase:** Publisher uploads PDF -> Saved to Firebase Storage -> Metadata (Price/Title) saved to Firestore.
2. **Preview Phase:** Researcher selects document -> Views available queries (No PDF payload sent to client).
3. **x402 Payment Phase:** Researcher types question -> Lute wallet prompts for 0.05 ALGO signature -> Transaction broadcasted to Algorand TestNet.
4. **Execution Phase:** Node.js backend intercepts request -> Verifies payment logic -> Parses PDF -> Passes strict system prompt to Gemini.
5. **Settlement & Provenance:** Gemini returns cited answer -> UI renders answer -> Zerion API generates an on-chain verification receipt.
